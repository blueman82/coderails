# Not Checked

Examine your recent responses. List all substantive claims you did not check. Include confident claims if you have no tool result, file read, or statement from the user to show they are correct.

For each claim, give:

- The claim in one sentence.
- Why you did not check it. Examples are cost, oversight, or an assumption that it was obvious.
- A check that can show if it is correct.

List all claims that meet these conditions. Do not defend them.
