## Coverage and audit limits

The session census is observed from readable local native files and uses the frozen start window. Metric denominators are narrower whenever the design requires independent inspection. The first completed root has a documented repair candidate but no independent incident-history audit; the other root was active at cutoff. The repair metric therefore has 0 independently audited roots. The 54 workers are included in the session census but are not independent root-run denominators. Missing or deleted files cannot be enumerated from a present-day directory listing. A current `progress.json` is a snapshot and cannot reconstruct every state transition. No operational target or causal claim about all post-cutover runs is inferred from these counts.
