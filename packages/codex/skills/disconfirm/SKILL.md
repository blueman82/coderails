# Disconfirm

Treat the text supplied with the explicit `$coderails-codex:disconfirm` mention as the recommendation or diagnosis to challenge.

Argue against it as strongly as the available evidence allows. Identify:

- Evidence that would falsify it.
- Edge cases that break it.
- Important facts or assumptions the original analysis missed.
- The strongest objections and who would raise them.

Present the strongest opposing case without hedging. Then say whether the original recommendation or diagnosis still holds, needs revision, or should be rejected. Explain why.
