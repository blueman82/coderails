# Disconfirm

Challenge the recommendation or diagnosis that the user supplies with the explicit `$coderails-codex:disconfirm` mention.

Use the available facts to make the strongest argument against it. Identify these points.

- Facts that would show it is incorrect.
- Unusual conditions where it breaks.
- Important facts or assumptions the initial analysis missed.
- The strongest objections and who would raise them.

Give the strongest argument against it without hedging. Then say if the initial recommendation or diagnosis holds, needs a change, or should be rejected. Give the facts that led to that verdict.
